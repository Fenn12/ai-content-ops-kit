## 2. 适用与不适用

**适用**
- 消费品（食品、家居、个护、服饰）小红书种草笔记初稿
- 需要批量产出、且有人工终审环节的场景

**不适用**
- 医疗、保健功效、金融理财类（合规风险高，不建议自动化）
- 需要真人出镜口播的脚本
- 品牌公关声明、危机回应

---

## 3. 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| `product` | 是 | 产品名 + 核心成分/工艺 + 一句话卖点 |
| `audience` | 是 | 年龄区间 + 身份 + 具体痛点（不接受「年轻女性」这类泛描述） |
| `scene` | 是 | 使用场景，越具体越好（如「加班到十点回家没力气做饭」） |
| `tone` | 是 | `克制` / `活泼` / `专业` 三选一 |
| `constraints` | 否 | 禁用词、竞品名、平台合规红线 |
| `variants` | 否 | 一次生成几版，默认 3 |

**输入不全时的处理**：如果 `audience` 或 `scene` 缺失，**不要猜**，返回追问清单。这条规则是为了避免模型自动补全出脱离真实的画像。

## 5. 生成规则

### 5.1 结构
1. **钩子（前 2 行）**：必须是具体场景或具体痛点。禁止「姐妹们」「谁懂啊」式泛开场。
2. **卖点推进**：按 `痛点 → 机制 → 体感` 三段走。
   - 痛点：说清楚原来怎么难受
   - 机制：产品为什么能解决（用可验证的表述，不做因果承诺）
   - 体感：用完具体是什么感觉
3. **结尾 CTA**：只能软引导（如「放在购物车里躺了一周」），禁止「点击购买」「赶紧冲」。

### 5.2 语言
- 每段不超过 3 行，避免大段文字
- 不使用「最」「第一」「国家级」「根治」「彻底」等绝对化用语
- 不做功效承诺（「7 天变白」「一周瘦 5 斤」一律禁止）
- 不拉踩竞品，不出现其他品牌名

### 5.3 合规
- 涉及成分、工艺、检测数据的表述，必须能在 `product` 输入中找到依据
- 找不到依据的，写入 `risk_flags`，不自行补全
- 母婴、食品类额外检查：不得暗示替代正餐或医疗建议

## 6. 自检清单（模型输出前必须跑一遍）

- [ ] 字数在 300–500 之间
- [ ] 钩子含具体场景或具体痛点
- [ ] 三段结构完整（痛点/机制/体感）
- [ ] 无绝对化用语（对照 `banned.txt`）
- [ ] 无功效承诺
- [ ] tag 5–8 个
- [ ] `risk_flags` 已标出所有无依据表述

任何一项不通过，**重写而不是输出**。

## 7. 与人工的分工

| 环节 | AI | 人 |
|---|---|---|
| 选题发散 | ✅ 批量给方向 | 定优先级 |

| 结构合规 | ✅ 自检 | 抽检 |

| 投放决策 | ❌ | ✅ |
